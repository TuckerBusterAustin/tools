Questions

What is free?

One client workspace. You can import HubSpot contacts, HubSpot deals and Trello CSVs, see the fixed-column preview, and download the clean files.

What does paying unlock?

Pro raises the limit from 1 to 5 client workspaces. It adds an export-due checklist for each client, with a last-exported date that turns due after 7 days. It also adds one click to download all of a client's files together.

How does my data get in?

You export a CSV from HubSpot or Trello as you do now. Then you pick the file in Sundayfile or paste its text. Sundayfile cleans it into the fixed columns.

Where does my data go?

Nowhere. Everything is saved in your own browser. Nothing is uploaded to a server.

What if I clear my browser or switch computers?

Data lives in one browser on one device. Clearing browser data removes it. Use the backup button in Settings to save a JSON file, and restore it when you need it.

Are the column names guaranteed to match my export?

Sundayfile recognizes the common HubSpot and Trello header names. Unknown columns are dropped, so check the preview before you download. Your output layout stays the same every time.
