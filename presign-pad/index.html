Presign Pad is in development.

Sign one AWS request. See why it fails. Nothing else to set up.

Presign Pad will be a small browser extension. It is not built yet. It will sign SigV4 requests and presigned URLs, send them, show the live response, and point to the likely cause when a request fails. Join the waitlist to hear when it launches.

The problem

  • You just need to fire off one signed request. Opening a full API client feels like too much.
  • A signing error often only shows up after you hit send. Then you get a vague 403 and have to guess.
  • Presigned S3 URLs are easy to get slightly wrong. A wrong header, region or timestamp breaks them.
  • Signing alone is not enough. You also want the request sent and the failure explained in plain words.
  • You don't want to paste your AWS keys into a tool that syncs them to a cloud workspace.

What it will do

  • Basic request signing for AWS-style requests (SigV4) and presigned URLs. This is what Presign Pad will do first.
  • Send the request from the extension and see the live response right next to it.
  • Real-time error highlighting. It will flag likely signing and syntax problems as you type, and explain the likely cause when a request fails.
  • No account is planned. It is being designed so your keys never leave your machine.
  • A free tier is planned. Its limits are not decided yet.
  • A single-purpose tool. It will not try to replace a full API platform.

FAQ

Does Presign Pad exist yet?
No. It is not built yet. This page tests whether enough developers want it. If there is enough interest, we will build it and email the waitlist.
What will it do?
It will be a browser extension. You will build a request, sign it with SigV4 or create a presigned URL, send it, and see the live response. When a request fails, it will highlight and explain the likely cause.
Will I need an account?
The plan is no. It is being designed so your keys never leave your machine.
Will it replace Postman?
No. It will focus on one job: signing, sending and debugging one-off requests. If you need collections, teams and collaboration, a full client is a better fit.
What will it cost?
A free tier and a paid Pro plan are planned. The planned prices are shown on this page. They are not final. The limits of the free tier are not decided yet.
What does the Reserve button do?
Each Pro plan has a Reserve button. Clicking it does not charge anyone. It shows a payment link if you want to pre-order. Pre-orders are fully refundable on request at any time. If Presign Pad is not built, pre-orders will be refunded. The refund date will be shown next to the payment link.
Which services will it support?
The first goal is AWS-style signed requests, such as S3. We will not promise other services until we have tested them.
What happens when I join the waitlist?
